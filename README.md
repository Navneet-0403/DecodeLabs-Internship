## Projects Directory

### [Project 1: Shield AI — AI Agent Security Shield](./shield-ai)
- **Role**: AI Agent Security Gateway & Command Center
- **Tech Stack**: HTML5 (Semantic Landmarks), CSS3 (Mobile-First, Grid, Flexbox, Container Queries), Vanilla JavaScript
- **Design Tokens**: Mocha Mousse (`#A47864`), Ethereal Blue (`#A0D4E0`), Moonlit Grey (`#F2F0EA`), Montserrat & Open Sans
- **Features**:
  - Security Command Center with real-time KPI telemetry
  - Rule-based Prompt Scanner for injection, override, and PII detection
  - Agent Monitor with policy verification workflows
  - Tool Permissions matrix with least-privilege toggles
  - Human-in-the-loop Approval Center
  - Threat Logs audit table with real-time filters
  - Interactive Attack Simulator
  - Fully responsive mobile drawer navigation and zero horizontal overflow across all viewports ($320\text{px} - 1920\text{px}$)
